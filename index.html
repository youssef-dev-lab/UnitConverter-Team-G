Unit Converter

Simple, reliable unit conversion — developed by Software Engineering Team G.

Python · pytest · GitHub Actions

About the Project

A Python application that converts values between length, temperature, and weight units, with input validation and automated tests.

Supported Conversions

Length

Convert between meters, kilometers, miles, and feet.

Temperature

Convert between Celsius, Fahrenheit, and Kelvin.

Weight

Convert between kilograms, grams, and pounds.

Quality & Testing

Automated tests are run with pytest through GitHub Actions to check conversion behavior and input validation.
