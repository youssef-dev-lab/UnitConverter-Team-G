# Unit Converter

## Overview
A Python application that converts values between different units of length, temperature, and weight.

## Features
- Length conversion: meters, kilometers, miles, and feet.
- Temperature conversion: Celsius, Fahrenheit, and Kelvin.
- Weight conversion: kilograms, grams, and pounds.
- Input validation and error handling.
- Automated unit tests using pytest.

## Testing
Run the tests using:

```bash
python -m pytest -v
```
